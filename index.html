Файл открыт в просмотрщике, а не в браузере. Печатать в полях можно, но пересчёта не будет: просмотрщик не выполняет скрипты. Цифры ниже — пример для значений по умолчанию.
Где считает: на компьютере — сохраните файл и откройте двойным кликом (Chrome, Safari, Edge); на Android — «Открыть с помощью» → браузер. На iPhone стандартный просмотр «Файлов» скрипты не запускает — нужен файловый менеджер со встроенным браузером либо ссылка на страницу.
А пока — считайте по таблице ниже.
