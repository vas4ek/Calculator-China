# Calculator China

Расчёт себестоимости закупки товара в Китае и цены продажи.

**Открыть:** https://vas4ek.github.io/Calculator-China/

## Что внутри

- **`index.html`** — основной калькулятор. Считает себестоимость в двух колонках:
  - *на момент закупки* — товар, доставка по Китаю, страховка, обрешётка и упаковка по курсам дня оплаты. Неполная модель: без фрахта и доставки по России, нужна только для сравнения;
  - *на момент получения* — те же затраты по новым курсам плюс фрахт Китай — РФ и доставка Москва — Тула. От неё считается наценка.

  Курсы задаются отдельно для каждого момента: ₽ за 1 ¥, ₽ за 1 $ и ¥ за 1 $. Страница показывает отклонение каждого курса (порог 2 % и 3 %), кросс-курс через доллар, расчётный фрахт по весу и ставке за килограмм, а также во что обошлась бы цена, назначенная по первой колонке.

- **`marshruty-obmena.html`** — ранняя версия: сравнение прямого обмена ₽ → ¥ с обменом через доллар.

## Как обновлять

Обе страницы — самостоятельные HTML-файлы без внешних зависимостей. Достаточно отредактировать файл и закоммитить: GitHub Pages пересобирает сайт за одну-две минуты.

Ключи доступа в репозитории не хранятся.
